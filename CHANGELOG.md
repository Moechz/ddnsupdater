# Changelog

All notable user-visible changes to the DDNS Updater TOS application package.

## 2.10.0-1 — 2026-11-11

### Added
- First release. DDNS Updater (`qmcgaw/ddns-updater:v2.10.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8079 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/ddnsupdaterdocker/`.
